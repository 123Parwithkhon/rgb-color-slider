# 🎛️ RGB Color Slider

An interactive web application that allows users to customize and generate custom RGB background colors in real-time using range sliders for Red, Green, and Blue channels.

## 🚀 Features
* Dynamic background color updating on slider input (`oninput` event)[cite: 11].
* Live text display of the current `rgb(r, g, b)` CSS code[cite: 11].
* Clean card-based layout centered with CSS Grid and modern shadows[cite: 12].

## 🛠 Technologies Used
* **HTML5** (Range input elements, custom script integration)[cite: 11]
* **CSS3** (CSS Grid, box-shadows, Google Fonts integration)[cite: 11, 12]
* **JavaScript** (DOM value retrieval, dynamic style manipulation)[cite: 11]

## 💻 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser[cite: 11].

# 🎛️ RGB Color Slider (Слайдер цветов RGB)

Интерактивное веб-приложение, которое позволяет пользователю в реальном времени настраивать и генерировать цвета фона с помощью ползунков (range) для каналов Red (красный), Green (зеленый) и Blue (синий).

## 🚀 Особенности
* Динамическое обновление цвета фона страницы при перемещении ползунков (событие `oninput`)[cite: 11].
* Живой вывод текущего CSS-кода `rgb(r, g, b)` в специальном блоке[cite: 11].
* Аккуратный дизайн карточки, центрированный с помощью CSS Grid[cite: 12].

## 🛠 Используемые технологии
* **HTML5** (элементы ввода range, интеграция скрипта)[cite: 11]
* **CSS3** (CSS Grid, тени, подключение Google Fonts)[cite: 11, 12]
* **JavaScript** (получение значений DOM, динамическое изменение стилей)[cite: 11]

## 💻 Как запустить
1. Клонируйте или скачайте этот репозиторий.
2. Откройте файл `index.html` в любом веб-браузере[cite: 11].
